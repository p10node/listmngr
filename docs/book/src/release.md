# Releases

A tagged version (`v1.0.0`) is built by the release pipeline: static
Linux binaries for `x86_64` and `aarch64`, macOS binaries, Debian and
RPM packages carrying the systemd unit, a multi-architecture container
image, a Helm chart, a CycloneDX SBOM, and `SHA256SUMS` signed with
cosign. Until the first tag, build from source as the
[Install](install.md) chapter says.
