listmngr {{ default .Chart.AppVersion .Values.image.tag }} is deployed as {{ include "listmngr.fullname" . }}{{ if .Values.postgresql.enabled }} with PostgreSQL {{ .Values.postgresql.image.tag }} as {{ include "listmngr.postgresqlName" . }} (its password was read at first start; keep it, or rotate it in SQL){{ end }}.

The web interface answers on the Service port {{ .Values.service.port }} (`/healthz`, `/readyz`, `/web`).
Create the first server owner from inside the pod:

  kubectl exec -i deploy/{{ include "listmngr.fullname" . }} -c listmngr -- /listmngr --config /etc/listmngr/listmngr.toml \
      user create admin@example.com --display-name Admin --server-owner --password-stdin < password

(The image is `scratch`: no shell and no PATH, so the binary is named by its path, `/listmngr`.)
Check the install: `helm test {{ .Release.Name }}`.
